# HISR

HISR 是一个以“文史哲不分家”为核心理念的生活反思与选择辅助应用。

用户描述现实中的困惑后，HISR 通过相似的历史案例、哲学视角和文学作品提供参照，帮助用户形成自己的判断，而不是替用户作决定。
